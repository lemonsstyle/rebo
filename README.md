# rebo：把微博网页变成更好读的信息流

微博网页版本来能看，但在大屏上总有点可惜：中间是一条窄窄的单列，右边塞满热搜和推荐，真正想读的关注内容反而占不了多少地方。

rebo 是一个本地 Chrome / Edge 扩展。它不替你接管微博，也不改你的账号；只把当前已登录页面里的信息流重新排成更适合阅读的样子。

## 用起来有什么不同

- **一屏能读更多。** 信息流可在三、四、五列之间切换；图片、短文字和长内容不再都挤在同一条纵向队列里。
- **分组不丢。** “全部关注”“最新微博”“特别关注”和自定义分组照常使用，切换时读取器跟着当前页面走。
- **图文更像在浏览。** 单图、多图、视频、外链预览和转发内容会按媒介类型整理；多图不会只剩一排同样大小的缩略图。
- **不用频繁跳页。** 点击卡片会在当前位置打开阅读详情，正文、媒体和评论放在同一处；想回到微博原页时仍可随时打开“原文”。
- **保留退路。** 左下角的开关可以立即切回官方页面；某个信息流请求不可靠时，rebo 也会自动让回原版列表，而不是留下空白页面。

rebo 更像给微博网页版加了一层“阅读桌面”：少一点边栏噪音，多一点内容密度；适合有很多关注分组、习惯在宽屏上慢慢刷微博的人。

## 安装

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 打开“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中本仓库目录。
4. 打开或刷新 `https://weibo.com/`，左下角出现橙色眼睛按钮即表示扩展已加载。

新布局默认开启，并默认使用三列。点击左下角按钮可关闭读取器或切换三、四、五列的信息密度；这些偏好只保存在浏览器本地。

## 它做什么，也不做什么

rebo 只处理微博网页已经展示给你的内容：当前分组信息流、长微博全文、详情评论和媒体预览。它不保存 Cookie、不会把信息流上传到其他服务器，也没有发微博、点赞、关注或转发等账号操作。

微博的网页结构和非公开接口会变化。遇到某个分组暂时无法读取时，关闭“使用新布局”即可回到官方单列信息流。实现细节、接口取舍和维护检查见 [TECHNICAL_SUMMARY.md](TECHNICAL_SUMMARY.md)。
