# rebo：把 weibo 变成更好读的 redbook

微博网页版本来能看，但在大屏上空间利用率太可惜。中间是一条窄窄的单列，右边塞满热搜和推荐，其余都是空白。

rebo 是一个本地 Chrome / Edge 扩展。它不替你接管微博；只把当前已登录页面里的信息流重新排成更适合阅读的样子。适合习惯在宽屏上慢慢刷微博的人。

## 用起来有什么不同

- **内容更多。** 信息流可在三、四、五列之间切换；图片、短文字和长内容不再都挤在同一条纵向队列里。
- **版型不变。** “全部关注”“最新微博”“特别关注”和自定义分组照常使用，切换时读取器跟着当前页面走。
- **均衡体验。** 单图、多图、视频、外链预览和转发内容会按媒介类型整理；多图不会只剩一排同样大小的缩略图。


## 安装

1. 下载本仓库已发布的[最新压缩包](https://github.com/lemonsstyle/rebo/releases/)，并解压到 xxx 文件夹。
2. 浏览器地址栏输入 `chrome://extensions`（Edge 输入 `edge://extensions`）。
3. 打开右上角“开发者模式”（Edge 打开左下角“开发人员模式”）。
4. 选择“加载已解压的扩展程序”，（Edge 点击“加载解压缩的扩展”），点击 xxx 文件夹。
5. 刷新 `https://weibo.com/`，左下角出现橙色眼睛按钮，即可启动本扩展插件的功能。

新布局默认开启，并默认使用三列。点击左下角按钮可关闭读取器或切换三、四、五列的信息密度；这些偏好只保存在浏览器本地。

## 处理范围

rebo 只处理微博网页已经展示给你的内容：当前分组信息流、长微博全文、详情评论和媒体预览。

它不保存 Cookie，也不会把信息流上传到其他服务器。不会自动发微博或关注；详情里的转发、评论和点赞只会在你亲自点击后，通过当前网页的微博同源接口发送。

微博的网页结构和非公开接口会变化。遇到某个分组暂时无法读取时，关闭“使用新布局”即可回到官方单列信息流。实现细节、接口取舍和维护检查见 [TECHNICAL_SUMMARY.md](TECHNICAL_SUMMARY.md)。
