# 微博网格阅读器

一个无需构建步骤的 Chrome / Edge Manifest V3 扩展，用于改善微博网页版首页和分组页的信息流阅读。

## 功能

- 在 `https://weibo.com/` 和 `/mygroups` 信息流页面左下角显示悬浮阅读器按钮。
- 默认隐藏原生右栏，扩大中间信息流，并使左侧分组导航在桌面宽度保持可见。
- 点击悬浮按钮打开紧凑控制面板，可开关新布局并选择卡片列数。
- 新布局始终隐藏微博右侧的热搜、超话、推荐、创作者中心和页面服务信息。
- 扩展从微博当前已登录页面的 `/ajax/feed/friendstimeline` 获取同一分组的信息流，在扩展内渲染独立的响应式卡片墙，不依赖微博纵向虚拟列表。
- 抽屉中的 `3 / 4 / 5` 按钮可调整卡片列数，默认三列以保持更舒适的卡片宽度；卡片按瀑布流落入最短列，不会因同一行的高卡片留下大块空白。多图微博会按横竖图方向组成紧凑拼图；视频微博使用原视频流预览。
- 转发微博在卡片内显示被转发微博的作者、正文及首个媒体内容。
- 下拉到卡片墙底部附近时，扩展用响应中的 `max_id` 请求下一页；路由切换或从微博详情返回信息流后会重新挂载卡片墙。
- 点击卡片会在原卡片附近打开较小的详情层：左侧显示完整正文和媒体，右侧默认显示评论；右上方的转发、评论、点赞标签可切换对应内容。浏览器返回只关闭详情层并回到原来的卡片墙位置。

## 本地安装

1. 在地址栏打开 `chrome://extensions`；Edge 使用 `edge://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`weibo_grid`。
5. 打开或刷新 `https://weibo.com/mygroups?gid=...`，页面左下角会出现橙色网格按钮。

首次使用时，新布局默认开启，默认三列。布局开关与列数偏好保存在浏览器本地扩展存储中，不会发送到微博或任何外部服务。

## 验证清单

加载扩展后请在已登录的微博页面验证：

1. 打开紧凑控制面板，切换“使用新布局”后确认原版信息流与右侧内容恢复或隐藏正确。
2. 在控制面板中选择 `3 / 4 / 5` 列；默认三列，所选列数会保存在浏览器本地。
3. 下拉至少三屏，检查卡片墙是否持续加载且不会出现行高空白。
4. 点击图文、转发和视频卡片，确认扩展内详情层显示完整内容与评论；点击“在微博中打开”才进入官方详情页。

## 文件说明

- `manifest.json`：Chrome / Edge 扩展清单和站点匹配范围。
- `content.js`：页面布局、紧凑控制面板、偏好保存、路由与独立瀑布流渲染逻辑。
- `page-bridge.js`：在微博页面主世界中请求已登录的信息流，不读取或传出 Cookie。
- `styles.css`：宽屏布局、抽屉界面和独立卡片墙样式。

## 隐私与限制

扩展只申请 `storage` 权限以及微博页面访问权限。它不读取或传出 Cookie，也不向微博以外的服务上传信息。信息流请求在用户已登录的微博页面上下文发出，返回内容只用于当前页面的本地卡片渲染。

微博会频繁更新其接口与响应字段。首次信息流请求失败时，扩展会自动恢复微博原版信息流，避免页面出现空白；也可通过关闭“使用新布局”立即恢复微博原版信息流。
