# 本地回归验证

不依赖额外包的单元测试：

```sh
node --test tests/*.test.cjs
```

浏览器回归需要环境中已有 Playwright 和 Chromium；本仓库不自动安装依赖。

```sh
node tests/browser-smoke.cjs
```

若 Playwright 位于外部运行时目录，可通过 `REBO_PLAYWRIGHT_MODULE` 指向已有包。该值仅用于测试进程。

浏览器测试拦截所有页面请求，用本地模拟数据检查 HTML 惰性解析、详情关闭、键盘焦点、点赞同步、回复预加载与展开后的草稿保留、快捷操作切换、视频回退及触屏样式。它不会使用个人浏览器配置或真实微博登录态。

测试在内存中暴露 content.js 的内部函数并模拟桥接响应，不能代替微博实际接口、CSP、页面结构和 SPA 导航的端到端验证。上线前仍需在微博页面手动检查：切组、连续分页、关闭/开启布局、文字评论与回复、点赞及取消点赞、媒体回退。
